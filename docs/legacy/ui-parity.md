# UI 对齐总清单（以 CodeOSS 为唯一基准）

> 状态：基准文档。**所有 UI 工作必须从本清单领取条目，禁止清单外零散修改。**
> 基准：VSCode（CodeOSS，MIT）1.9x 默认键位与 Dark Modern 交互。每项验收 = 行为与 VSCode 一致 + 配套测试绿。
>
> 规则：
> - 「废除」= 原 spec-v2-ui.md 的有意偏离作废，改为 VSCode 原生行为。
> - 「保留」= 技术上无法对齐的偏离，说明原因后不再重议。
> - 波次：W1 键位与快捷入口 → W2 外壳结构 → W3 编辑器区 → W4 通知与状态栏 → W5 设置与收尾。

## 0. 总体决定

| 决定 | 内容 |
|---|---|
| 废除 | ≡ 单按钮双层菜单 → 改横向菜单栏（悬停切换、Alt 助记键、check 项、分隔线） |
| 废除 | 居中模态 showMessage/confirm → 改右下角通知 toast（可堆叠、多按钮、进度）+ 必要时保留模态确认 |
| 废除 | 设置对话框 → 改设置编辑器（占编辑区、目录树 + 搜索 + 即时生效 + 修改标记） |
| 保留 | 远程目录选择器自绘（OS 原生选择器无法访问远端 FS） |
| 保留 | 无扩展系统（项目不引插件市场，活动栏不放扩展图标） |
| 对齐 | 全部快捷键按 VSCode 默认键位表实现（§1） |
