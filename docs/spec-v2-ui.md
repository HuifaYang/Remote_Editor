# 分册 2 · UI 全规格（每个视图的状态、文案、尺寸、交互）

> 对应 `src/renderer/`。**所有中文文案必须原样使用**（用户会逐字对照）。
> 尺寸单位 px；跟随全局缩放的部分标注 `×scale`（`scale` = 0.7~2.0 的界面缩放系数）。
> 颜色一律取 `styles/tokens.css` 变量，**禁止**写死颜色值。

## U1 主窗口外壳

- 窗口：`frame:false`；默认尺寸 1280×800；最小 960×600；记住上次尺寸与位置（`settings.json`）。
- 标题栏（高 32×scale）：左 = 菜单按钮 `≡`（弹出 文件/编辑/查看/终端/帮助）；中间 = `<当前文件名> - <主机名> - RemoteCodeEditor`；右 = `─` `□` `✕`（各 46×32 热区，图标 16×16 居中）。
  - `─` 最小化；`□`/`❐` 最大化↔还原（图标随状态切换）；`✕` 退出（有未保存先弹确认）。
  - 标题栏空白处**双击 = 最大化/还原**；拖动 = 移动窗口；窗口贴边时拖动 = 还原并跟手。
  - 窗口边缘 8px 热区可缩放（四角 + 四边，光标对应方向箭头）。
- 活动栏（宽 44×scale，背景 `--bg-editor`，右侧 1px `--divider`）：
  - 图标按钮 44×44，图标 24×24，悬停 `--bg-hover`；**选中 = 左侧 2px `--accent` 竖线 + 图标变亮**（无背景块）。
  - 顺序（自上而下）：`资源管理器`（files 图标）`搜索`（search）`源代码管理`（source-control）`远程主机`（remote）`分隔线` `设置`（settings，固定底部）。
  - 点当前已选中的视图 = **收起侧边栏**；点其它 = 切换。
- 侧边栏（宽 260×scale，可拖 200~480，背景 `--bg-panel`，右侧 1px `--divider`）：
  - 顶栏（高 35×scale）：标题（大写风格，如 `资源管理器`）+ 右侧 `⋯` 按钮 + 视图自带的图标按钮行。
  - 侧边栏可整列收起（`Ctrl+B`），收起后活动栏图标仍可见。
- 底部面板（高 240×scale，可拖 80~窗口高度 70%，顶部 1px `--divider`）：
  - 工具条（高 35×scale）：左 = 面板标签（`终端`/`输出`），右 = `新建终端 (+)` `终止 (trash)` `收起 (chevron)`。
  - 面板标签切换 = 显示对应内容区；`输出` 显示应用日志尾部（只读、可复制）。
- 状态栏（高 24×scale，背景 `--bg-panel`，顶部 1px `--divider`）：
  - 左：`⚡ 已连接·<主机名>` / `⚡ 未连接`（点击弹连接/断开菜单）｜当前文件名（点击弹已打开文件列表）｜`Git: <分支> +<新增> ~<修改> -<删除>`（点击弹分支菜单）。
  - 右：保存状态（`已保存`/`未保存`/`自动保存中…`/`保存失败`）｜**镜像过期时**插入 `镜像可能过期，按 F5 同步`（弱化色，点击即同步）｜编码（`utf-8`）｜语言（`C++`/`Python`…）｜`行 <n>，列 <n>`。
  - 空值项**隐藏**（不显示 `-`）；每项悬停有 `--bg-hover` 圆角背景，光标手型。

## U2 侧边栏·资源管理器

**结构**：单列树（行高 22×scale），根节点 = 工作目录 basename。
- 行内容：16×16 文件类型图标 + 文件名（**永不被截断**：名称列按内容展开，上限 = 视口宽 − 88；目录列是辅助信息，窄了截它）+ 行右端彩色状态字母（`U/A/M/D/R/!`，无底色方块，颜色 = `--git-*`）。
- 排序：目录在前、文件在后；各组内按名称不区分大小写排序。
- 目录懒加载：首次展开发 1 次 `listDir`；结果缓存 120 秒（上限 200 条）；**后台预取最多 3 个子目录**；同一条目录在飞行中只发一次请求（去重）。
- 状态着色：文件名前景 = 变更色（`--git-added/modified/deleted`）；未变更 = `--fg`；目录 = 子树内最高优先级变更色（优先级 modified > added > deleted）。
- Tooltip（悬停 600ms 出现）：
  ```
  <远端绝对路径>
  类型: <文件|目录>
  大小: <12.3 KB>
  修改时间: <2026-09-21 12:00:00>
  权限: <rw- r-- r-->
  Git: <未变更|已修改 [M]|新增 [U]|…>
  ```
- 右键菜单（每项带图标）：`新建文件…` `新建文件夹…` `重命名…` `删除`（红色）`刷新` `复制路径` `属性`。
  - `删除` 弹确认框：标题 `删除`，正文 `确定删除远程路径吗？\n<path>\n\n目录将被递归删除。`，按钮 `取消` / `删除`（红）。
  - `属性` 弹提示框（标题 `属性`）：`路径: …\n类型: …\n大小: …\n修改时间: …\n权限: …`。
- 顶栏图标按钮（24×24，悬停圆角背景）：`新建文件` `新建文件夹` `刷新` `折叠全部`。
- 空态（未连接）：居中灰色文本 `尚未打开工作目录` + 下方按钮 `打开远程文件夹…`（未连接时禁用，提示 `请先连接主机`）。
- 加载态：目录下临时行 `加载中…`（斜体灰）；失败行 `加载失败：<原因>`（红）+ 点击重试。

## U3 侧边栏·搜索

**结构**：查询行 + 状态行 + 结果树。
- 查询行：输入框（占满）+ `Aa` 开关（区分大小写，选中 = 高亮底）+ `.*` 开关（正则）。回车触发搜索；输入框有清除按钮 `✕`。
- 状态行（高 22）：`正在搜索…` / `3 处结果，分布在 2 个文件中` / `未找到` / `请先连接主机，再搜索` / `搜索失败：<原因>`。
- 结果树：**分组行** = 文件名（**加粗**）+ `（N）` + `　` + 相对目录（弱化）；**命中行** = 弱化行号 `行 224：` + 正文（正常色）+ **命中片段加粗高亮 `--accent`**。
- 点命中行 → 打开文件并跳到该行（文件未打开先记下目标行，加载完跳过去）。
- 打开面板本身 **0 远端请求**；只有回车或点刷新按钮才发 1 条 grep。
- 选项状态记忆（本次会话内）；正则非法时状态行显示 `正则表达式无效`。

## U4 侧边栏·源代码管理

**结构（自上而下）**：
1. 提交区：输入框（placeholder = `消息（Ctrl+Enter 在"<分支>"上提交）`，分支为空时 `消息（回车提交）`）+ 绿色拆分按钮行。
   - 左半 `✓ 提交`（图标 = Codicons `check`，白色；背景 `--commit-green`，悬停 `--commit-green-hover`）；右半 = 下拉箭头（同色，宽 28，左侧 1px 分隔线，图标 chevron-down 白色）。
   - **两半同高**（图标 12 + 上下内边距 8 = 文字 12pt + 上下 6）。
   - 有更改（且不在提交中）时两半都可点；**没写提交信息点「提交」= 状态栏提示 `请先填写提交信息`，不弹窗**；没有更改时两半都禁用（灰底 `--bg-panel` + 灰字）。
   - 下拉菜单（左对齐于右半）：`提交(修改)` `提交和推送` `提交和同步`。各项图标分别为 edit / upload / sync。
2. 「更改」分组：折叠箭头（左，展开=chevron-down、折叠=chevron-right）+ 标题 `更改` + 数量（弱化）+ 右侧刷新图标（tooltip `刷新 Git 状态（Shift+F5）`）。
   - 行 = 文件类型图标 + 文件名（优先占宽）+ 弱化相对目录 + 行右端彩色字母。
   - 点行 = 打开该文件。
3. 「图表」分组（**默认折叠**）：折叠箭头 + 标题 `图表` + 右侧刷新图标（tooltip `刷新提交历史`）。
   - 展开时才发 1 条 `git log`；换仓库时清空旧图但**不自动重取**。
   - 行 = 左侧泳道（线宽 2，颜色按泳道序号循环取 8 色：`#58a6ff #3fb950 #d29922 #db61a2 #a371f7 #39c5cf #ff7b72 #e3b341`）+ **空心圆点（半径 3.6，点中变实心 + 整行底色 `--bg-selected`）** + 右侧：引用徽章（分支/标签，圆角小牌，底 `--bg-hover`）+ 提交标题（正常色）+ 第二行弱化 `短哈希 · 作者 · 相对时间`。
   - 行高 = 2×字号；悬停出 tooltip：`<短哈希>\n<完整标题>\n<作者> · <相对时间>`。
4. 「更改」与「图表」之间 = 可拖分隔条（热区 6px，默认画 1px 中线，悬停/拖动整条变 `--accent`）。
- 空态：`没有检测到更改。`（居中灰字）。
- 打开面板本身 **0 远端请求**。

## U5 侧边栏·远程主机

- 分组树：`SSH` 组下每个主机一行（图标 remote + 显示名 + 右侧图标：编辑 `✎`、删除 `🗑`、连接 `⚡`）；展开显示**历史工作目录**（图标 folder + 路径，点 = 连接并打开该目录）。
- 底部按钮行：`+ 新增` `从 ~/.ssh/config 导入`。
- **底部凭据输入行**（仅认证需要时出现，不弹居中对话框）：标签（`密码`/`私钥口令`）+ 输入框（密码型）+ `连接` 按钮；回车即连。
  - 密码主机且本机有**默认名**私钥（`id_ed25519/id_ecdsa/id_rsa/id_dsa`）→ **不问密码直接连**（状态栏显示 `正在连接 <目标>（先试本机私钥）…`）；被拒后回到该输入行，标签 `密码`，提示 `本机私钥未被接受，输入密码后回车连接`。
  - 本机没有默认名私钥 → 直接出密码输入行。
  - 私钥认证主机 → 直接连；私钥有口令时出 `私钥口令` 输入行，提示 `该私钥有口令，输入后回车连接（无口令可留空）`。
- 空态：`还没有主机` + `新增主机…` 按钮。

## U6 编辑区（标签页 + Monaco）

- 标签页行（高 32×scale，背景 `--bg-window`）：标签 = 16×16 文件类型图标 + 文件名 + 脏点（未保存显示 `●`，已保存显示 `✕`，悬停 `✕`）+ 右侧固定 `+`（新建文件）。标签可拖动排序；中键关闭；右键菜单：`关闭` `关闭其它` `关闭右侧` `全部保存`。
- Monaco 容器：占满剩余空间；主题深色/浅色跟随应用主题（`monaco.editor.defineTheme`，tokenColors 用 §6.2 的 tokens）；`fontSize` = 设置值 × scale；`lineNumbers: on`；`minimap: { enabled: true }`；`renderWhitespace: selection`；`wordWrap` 跟随设置。
- Monaco 自带能力**必须开启**：补全（`quickSuggestions`）、参数提示、悬浮文档、诊断波浪线、多光标、查找替换、小地图、缩进指南。
- LSP 接入：`Ctrl+Space` 触发补全、`F12` 跳定义、`Shift+F12` 查找引用、悬浮提示、诊断 = `setModelMarkers`。
- 无标签空态：欢迎页 = 大标题 `RemoteCodeEditor` + 副标题 `轻量级 SSH 远程代码编辑器 · 远端零部署` + 按钮 `连接主机…`（连接后出现 `打开远程文件夹…`）+ 快捷键提示三行：
  ```
  Ctrl+O 打开远程文件夹    Ctrl+Shift+F 全局搜索    Ctrl+` 打开终端
  ```
- 脏标记与自动保存：停止输入 1.5 秒（可设置 500~3000ms）自动上传；自动保存失败**只提示不弹窗**（状态栏 `自动保存失败：<原因>`）。

## U7 底部面板·终端

- 工具条：`终端` 标题 + 页签条（每终端一个页签：图标 terminal + 名称 `终端 1`… + 悬停出现 `✕`）+ 右侧按钮 `+`（新建，tooltip `新建终端（Ctrl+Shift+`）`）`trash`（终止当前，tooltip `终止当前终端`）`chevron-down`（收起面板）。
- xterm.js：主题色 = `--bg-editor` 底 + `--fg` 字；字体 `JetBrains Mono, Consolas, monospace`，字号 = 编辑器字号 × scale；光标块状闪烁；右键 = 粘贴（`Ctrl+Shift+V` 同）。
- 滚动：Shift+PgUp/PgDn 翻页；回滚 5000 行。
- 无终端空态：`没有打开的终端。\n点右上角「+」新建一个。`
- 关闭面板 = 收起（终端进程保持）；从菜单 `终端 → 新建终端` 再次展开。
- **终端执行过任何命令后**把镜像标记为「可能过期」（用户可能在终端里改了文件）：状态栏出现 `镜像可能过期，按 F5 同步`；补全继续可用（可能基于旧代码）。

## U9 设置对话框

分组（小标题 = 弱化加粗，无边框）：
1. **外观**：主题（下拉：深色/浅色）｜界面字体（文本框，留空=系统）｜界面字号（8~32）。
   （v2 不做用户可替换资源目录，见总纲 §1.4。）
2. **编辑器**：缩进宽度（1~16）｜使用空格缩进（勾选）｜自动换行（勾选）｜显示行号（勾选）｜高亮当前行（勾选）｜自动保存（勾选）｜自动保存延迟（500~30000 ms）。
3. **文件**：最大打开文件（1~512 MB）。
4. **SSH**：连接超时（3~300 s）｜Keepalive（0~300 s，0=关）｜严格校验 known_hosts（勾选）。
5. **语言服务**：语言服务位置（单选：`本机（默认）` / `板子上（备用）` / `关闭`，写 `settings.lspTransport`）｜启用代码补全（勾选，默认开，写 `settings.lspEnabled`）｜C++ 服务器路径（留空 = 用内置 clangd，见总纲 §5.5 第 0 条）｜Python 服务器路径（默认 `python3 -m pylsp`）｜只读说明：`板子无需安装任何东西；「本机」模式语言服务在工作机运行（板子 0 占用），「板子上」模式经 SSH 拉起（板子占 50~400MB 内存，适合环境镜像太大的场景）。`

按钮行右对齐：`取消`（普通）/ `确定`（accent 实心）。
